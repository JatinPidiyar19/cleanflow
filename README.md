# CleanFlow

A universal data cleaning and validation web app built with Python and Streamlit.

CleanFlow allows users to upload messy tabular data, analyze common data-quality problems, clean safe issues automatically, validate the result, and download the cleaned dataset.

## Features

- Upload CSV, Excel, JSON, and PDF files
- Automatic data inspection
- Duplicate detection and removal
- Text standardization
- Date detection and cleaning
- Invalid-value detection
- Missing-value reporting
- Data validation
- Cleaning summary and validation report
- Download cleaned data as CSV
- Download cleaned data as Excel
- Download a PDF preview
- Streamlit web interface

## Supported Files

| Input | Supported |
|---|---|
| CSV | Yes |
| Excel (.xlsx) | Yes |
| JSON | Yes |
| PDF | Yes |

PDF support is focused on tabular data. The PDF output generated by CleanFlow is a preview; CSV and Excel contain the complete cleaned dataset.
